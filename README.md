# Authenticating-the-signature-using-MD5-hash-algorithm

## Description
This project demonstrates **digital signature authentication** using the **MD5 hash algorithm** and **RSA keys**. It shows how to verify message integrity and authenticity.

## Requirements
- Python 3.x
- `rsa` library (`pip install rsa`)

## Usage
1. Open `lab_task_4.ipynb` in Jupyter Notebook.
2. Run the notebook to:
   - Generate RSA keys
   - Compute MD5 hash of the message
   - Sign the hash with the private key
   - Verify the signature with the public key
